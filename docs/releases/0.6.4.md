# Release 0.6.4 (2026-11-19)

Previous release: 0.6.3. A patch release of the demo data tools and one install note.
The application itself is unchanged.

## Highlights

- **The demo can be rebuilt under HL-LAP-POLICY-2026.14.** The scripts that rebuild the
  area manager's lower-rate requests still built files for the previous policy, so every
  request was refused. Rehearsed on a copy of the AWS database, they now produce 15
  applications and 13 rate requests, all priced under 2026.14.
- **What the new policy means for those requests.** Under 2026.14 the engine
  recommends most grade-A files at the policy floor (the card rate less 60 bps). An RM's
  request for a lower rate is then below the floor, and the area manager can approve only
  down to the floor, or decline.

## Changes

### Changed
- `requirements-optional.txt` notes that LightGBM needs the OpenMP runtime on Linux
  (`apt install libgomp1`). Without it LightGBM cannot load and model selection quietly
  trains other learners, so a server's models differ from the ones tested elsewhere.

### Fixed
- The demo data scripts (`scripts/demo_scenarios.py`, `scripts/seed_demo_cases.py`)
  still built files for HL-POLICY-2026.13: 15-25 year tenures, competitor offers around
  9%, incomes sized for 20-year EMIs and one bureau score under the new 675 minimum.
  Under 2026.14 every rate request was refused. They now use tenures of at most ten
  years, competitor offers in the 13-17% market and incomes that pass the stressed
  affordability test, and each case still shows the decision it was built for.
- `scripts/seed_demo_cases.py` sent files to the area manager without the customer
  interaction the readiness check requires (existing customer, conversation notes,
  negotiation rounds), so its rate requests were refused. Each seeded file now answers
  them.

## Upgrade steps

To rebuild a server's demo data under the policy in force (back up first; it removes
every loan file):

1. `python scripts/demo_reset.py`, which copies the store beside itself, then clears.
2. `python scripts/demo_scenarios.py --base http://127.0.0.1:8000` (10 requests).
3. `python scripts/seed_demo_cases.py --api http://127.0.0.1:8000` (5 cases; it prints
   the customers' temporary passwords once).

On Linux, LightGBM needs `apt install libgomp1`.

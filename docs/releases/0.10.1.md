# Release 0.10.1 (2026-11-23)

Previous release: 0.10.0. A patch release of one rule at the API. The policy
(HL-LAP-POLICY-2026.14) and the models are unchanged.

## Highlights

- **No request outside 13-17% reaches the area manager.** After the approval list was
  trimmed to 10, testers signed in as the RM added six requests on AWS, two of them asking
  12.73%. No rate below 13% can be approved, so such a request only filled the list with
  something to decline. The RM now gets a clear message instead: the rate is outside the
  policy band of 13.00% to 17.00%. The six test requests were removed (backed up first) and
  the list is back to its 10.

## Changes

### Fixed
- An RM could ask the area manager for a rate outside the policy band (13.00-17.00%): on AWS a
  request at 12.73% reached the approval list, although no rate below 13% can ever be
  approved. The request is now refused with the band in the message
  (`reference.card_rate_floor` to `card_rate_ceiling`). Requests already raised are untouched.

## Upgrade steps

Deploy the API (and the web application, for the version number). Nothing else changes.

## Known issues

- Everything listed under Known issues in 0.10.0 still stands.

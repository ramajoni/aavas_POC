# Release 0.7.1 (2026-11-19)

Previous release: 0.7.0. A patch release for the policy kit on Windows; nothing else changes.

## Highlights

- **The policy kit's tests pass on a fresh Windows clone.** Git converted the kit's
  generated files to CRLF line endings, which the drift test rightly rejects. They now
  stay LF everywhere.

## Changes

### Fixed
- On Windows, with `core.autocrlf` on, git checked out the generated policy kit files
  with CRLF line endings, and two of the kit's drift tests failed on a fresh clone.
  `.gitattributes` now keeps `policy_kit/*.json`, `*.yaml` and `*.md` as LF in every
  checkout.

## Upgrade steps

None. A clone made before this release can refresh its kit files with
`git rm --cached -r policy_kit && git checkout -- policy_kit`.

## Known issues

- Everything listed under Known issues in 0.7.0 still stands.

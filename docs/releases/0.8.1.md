# Release 0.8.1 (2026-11-20)

Previous release: 0.8.0. A patch release for setting up OmniXAI on a server; the app is unchanged.

## Highlights

- **OmniXAI sets up on a server without a compiler.** The explainability environment no
  longer compiles hnswlib from C++. It installs a prebuilt wheel on every platform, so the
  AWS server can generate the Model Explainability reports.

## Changes

### Fixed
- `scripts/setup_xai_env.sh` compiled `hnswlib` from source on Linux, which needs a compiler
  toolchain the production server does not have (and should not need). It now installs
  `hnswlib` only as a prebuilt wheel, falling back to `chroma-hnswlib` (the same library,
  prebuilt) on every platform, as it already did on Windows.

## Upgrade steps

None for the app. To build the explainability environment on a server:
`XAI_BASE_VENV=<the app's venv> XAI_VENV=<new folder> bash scripts/setup_xai_env.sh`, then
`scripts/run_omnixai.py --no-ui` with that environment's Python.

## Known issues

- Everything listed under Known issues in 0.8.0 still stands.
